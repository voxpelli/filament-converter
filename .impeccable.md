## Design Context

### Users
3D printing enthusiasts converting Bambu Studio filament profiles for use in PrusaSlicer. Technical users comfortable with slicer software, G-code, and filament properties. They want to get in, convert, and get out — the tool should not demand attention.

### Brand Personality
**Warm, Precise, Understated.** Nordic craft sensibility — the tool equivalent of a well-made hand plane. No decoration for its own sake.

### Aesthetic Direction
- **Design system:** Sovereign Warmth — warm canvas tone, falu red accents, cloudberry amber highlights, stone borders
- **Typography:** Public Sans (UI), Newsreader (body), JetBrains Mono (code)
- **References:** prusa3d.com (clean technical documentation), Linear (precision, quiet polish), Stripe (effortless competence), Printables (maker community warmth)
- **Anti-references:** Flashy SaaS landing pages, gamified UIs, anything with confetti or achievement badges
- **Theme:** Light mode is the identity (warm canvas tone). Dark mode planned for later — use custom properties exclusively so a single `@media (prefers-color-scheme: dark)` block can override.

### Emotional Goal
**Efficient satisfaction** — "That was fast and painless." The tool fades into the background. Delight comes from the absence of friction, not from decoration.

### Design Principles
1. **Warmth through materials, not effects** — colour, typography, and spacing do the emotional work. Animations only communicate state changes.
2. **Precision over personality** — data is presented clearly with good hierarchy. No cute copy or playful labels.
3. **Respect the user's time** — every interaction should feel instant. Animations are short (< 400ms) and functional.
4. **Accessible by default** — honour `prefers-reduced-motion`, maintain contrast ratios, keep keyboard navigation working.
5. **Zero dependencies** — CSS animations + vanilla JS only. No libraries for what CSS can do natively.
